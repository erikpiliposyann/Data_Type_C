# 🧠 C Language — struct, union, enum Practice

This repository contains practical exercises in C programming focused on:
- `struct`
- `union`
- `enum`
- combined data modeling

---

## 📚 Topics Covered

- Basic and advanced `struct` usage
- Memory-efficient `union` usage
- Type-safe `enum` design
- Real-world modeling (students, vehicles, employees, shapes, messages)

---

## 📁 Tasks Overview

### 🟢 Task 1 — Student Information
Represents students with:
- ID
- Study type (school/university)
- Score

---

### 🟢 Task 2 — Vehicle Information
Models vehicles using:
- `enum` (Car / Bike)
- `union` (doors / engine capacity)
- ID number

---

### 🟢 Task 3 — Shapes
Represents geometric shapes:
- Circle (radius)
- Rectangle (width, height)

---

### 🟢 Task 4 — Employee Payment System
Employee salary types:
- Hourly (hours + rate)
- Fixed salary

Uses `enum + union` combination.

---

### 🟢 Task 5 — Message System
Message types:
- Login message (user ID)
- Data message (number)

Uses type-based `union` storage.

---

### 🟡 Task 6 — Number Storage (Union Demo)
Stores same variable as:
- int
- float

Demonstrates memory sharing.

---

### 🟡 Task 7 — Simple Data Holder
Stores either:
- character
- integer

Shows how union overwrites memory.

---

## 🧠 Key Concepts Learned

- Struct grouping of data
- Union memory sharing
- Enum type safety
- Real-world modeling in C
- Input/output handling
- Type-based logic switching
